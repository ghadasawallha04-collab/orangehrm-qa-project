# OrangeHRM QA Project 🧪

## Project Overview
This repository contains a complete Quality Assurance (QA) project conducted on the
OrangeHRM open-source Human Resource Management system.

The project focuses on manual testing activities, including test planning, test case
design, execution, and reporting, following a real-world QA workflow.

> ⚠️ Note: This repository does NOT include the OrangeHRM source code.  
> OrangeHRM is an open-source HRM system, and all rights belong to its original owners.

---

## Testing Scope
The testing activities covered the following modules:
- Login & Authentication
- Employee Management
- Leave Management
- User Roles & Permissions

---

## My Role
As a QA Engineer, my responsibilities included:
- Writing the Test Plan document
- Designing manual test cases
- Executing both self-written and peer-written test cases
- Recording test execution results
- Preparing the Test Summary Report

This project demonstrates hands-on experience with planning, execution, collaboration,
and reporting within the software testing lifecycle.
